## ¿Qué incluye?

- `Nodo<T>`: estructura encargada de almacenar un dato y sus respectivos hijos izquierdo y derecho.
- `Arbol_Binario<T>`: clase genérica que administra la raíz del árbol y permite realizar recorridos recursivos.
- `preorden()`: recorre el árbol visitando primero la raíz, después el hijo izquierdo y finalmente el derecho.
- `postorden()`: recorre los nodos visitando primero los hijos y dejando la raíz para el final.
- **Recursividad:** utilizada para recorrer los nodos sin necesidad de recurrir a ciclos tradicionales.
- **Generics:** permite que el árbol pueda trabajar con distintos tipos de datos sin depender exclusivamente de una clase específica.
